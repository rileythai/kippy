# 31: Cursor key `u` undoes the last view change

status: done: key u steps back through cursor-mode views, checked by scripted png comparisons
opened: 2026-11-05

## Goal

In cursor mode, `u` restores the view before the last view change. Done when scripted `key` runs show the png after `u` is byte-identical to the png before the undone action, and `docs/commands.md` lists the key.

## Spec

- `kipp_action` snapshots the view before each key and pushes it when the limits differ after the action (so cancelled selections and clamped pans record nothing).
- Limits stored in seconds (or model number) and cgs, so the auto time unit changing between push and undo does not shift the restored view. Auto flags restored too.
- `kipp_rebuild` (xaxis/yaxis) clears the history. `units` keeps it.

Decision (2026-11-05, user): every cursor-mode view change is recorded (drag zoom, x/y range, z/Z/scroll, h/j/k/l pan, c centre, r reset). Unbounded stack. Cursor mode only: REPL `xlim`/`ylim`/`reset` are not recorded; the history survives leaving and re-entering cursor mode. Branch `undo-view` off main.
