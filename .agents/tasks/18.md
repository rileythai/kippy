First macOS CI run (arm64) failed linking giza's `libgiza-osxcocoa-main` (`giza_main` undefined): giza's libtool 2.4.6 only adds `-undefined suppress` on darwin when `MACOSX_DEPLOYMENT_TARGET` is unset or 10.x, and cibuildwheel always sets it; fixed in `3c02598` by making only `libgiza.la giza-fortran.lo` in `giza-build/src` (also skips libpgplot/libcpgplot/tests). Third run: arm64 wheel built and passed the smoke test, but the `otool -L` check step failed before checking anything because `unzip -d unpacked/<whl>` only creates the last path component; added `mkdir unpacked` (reproduced with Info-ZIP on Linux). The failed step also skipped the artifact upload. macOS user docs: `install.md` `macOS` section (15.0 wheel floor, XQuartz via `brew install --cask xquartz`, log out and in if `DISPLAY` is empty, headless fallback, no `p` clipboard), `xcode-select --install` in the source requirements, macOS notes in usage/api/README, and the broken headless-mode sentence in `usage.md` fixed; zensical build clean.
