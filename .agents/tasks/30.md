## Goal

In cursor mode, `v` prints one line to the console describing the model/zone cell under the cursor. Done when `key v x y` (KIPP_SCRIPT) prints values that match hand-computed ones from a fixture, and `docs/commands.md` lists the key.

## Spec

- Cell: model strip from `xedge` (bisect on the cursor x after `inv_x`), zone from the model's `xmcoord`/`rncoord` faces (cursor y after `inv_y`, times `yscale()`). On a .cnv the zone is a stored coordinate interval, not a KEPLER zone.
- Line: model number (ncyc), model time (or ncyc on a model axis) in display units, zone index, zone face range in mass/radius display units, convection type (`yzip`), colour value.
- Colour value: column fields print the bin's value range (`field_level` inverse, log10 when log-binned, follows the `-N` scale once task 29 is in), e.g. `log T_K = 6.75 - 6.80 (bin 14/24)`. Energy layers print the level as the colorbar labels it, e.g. `log epsnuc = 3 (gain)`. Raw values are not stored.
- Cursor outside the data prints a short "no cell" line.
- Shared path: add a case to `kipp_action`, so the scripted `key` command tests it; add the key to `cursor_help`.

Decision (2026-10-30, user): bin range, not raw values (raw would mean reader changes and nmodels x nzones x nfields x 8 B). Key `v`. Line holds cell identity + convection type + colour value, not just the cursor position. Build after task 29 merges into main (user merges).

Decision (2026-10-30, user): zone j is `[coord(j), coord(j+1))` for j = 1..ncoord-1, anything outside that or `[xedge(1), xedge(n+1))` prints "no cell"; convection type from `mbound` (matches the hatch); numbers in the `fields` list style (es, 4 significant figures); energy level 0 prints "below the lowest level"; time absolute in the current time unit, omitted on a model axis. Decision (2026-10-30, user): ranges in the line use ` .. `, like the `fields` list; the user confirmed `v` behaves as expected in a live window.
