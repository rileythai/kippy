status: done: check passes on unchanged code and fails on altered references
opened: 2026-11-06

## Goal

`tools/golden.py` pins convview's current output so code can move between modules with proof that nothing changed. Done when `check` passes against references written from unchanged code, and fails when one reference is altered.

## Spec

- `write REFDIR INPUT...` renders a fixed command script per input; `check REFDIR INPUT...` renders again and compares.
- Compared: every PNG byte for byte, every PDF after rasterising with `pdftoppm` (cairo's font subset tags change per run, so raw PDFs differ), and the stdout transcript (covers `key v` cell prints and messages).
- Inputs: `~/projects/keppy/convdata.cnv` (energy layers), the user's `seq.xxx` (column fields), and the synthetic `.kipp` from `tools/smoke_test.py`.
- Cursor code is driven headless with `key` under `KIPP_SCRIPT=1`.

Decision (2026-11-06, user): byte-identical comparison, no tolerance. Start the refactor with this harness. Inputs: keppy's `convdata.cnv` and a `seq.xxx`.

Measured: one `.cnv` load and render 2.5 s, the 3.9 GB repo-root `seq.xxx` 33 s. Two identical runs give identical PNGs; PDFs differ raw but rasterise identically.
